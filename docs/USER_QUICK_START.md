# Spyder KPI Dashboard 1v0 - User Quick Start

1. Open the dashboard link from IT.
2. Run the SAP query export.
3. Export the result to Excel.
4. Upload the Excel file into the dashboard.
5. Use the Order Health and Purchase Order tabs to review risks, reschedules, OTD, and notes.

Notes and override dropdown selections save in your own browser. If you switch computers or browsers, those saved notes will not follow automatically.
