1v5: shared report storage on Cloudflare Pages (functions/api/report.js, Workers KV binding REPORT_STORE):
the last uploaded report is kept on the server for everyone who signs in until a new upload replaces it;
hosts without it keep the report in each browser. Sidebar shows where the report is saved.

1v6: shadcn-style look in plain CSS (zinc neutrals, 12/8/8 px corners, hairline borders, one focus ring, Inter with
the system font as fallback, roomier spacing; print stays compact). Plain-English tooltips on every card, tile, chart
bar, column heading, filter, button and page link (hover, keyboard focus, or press and hold on a phone), ⓘ buttons
that explain each section (and the same texts under "About these numbers" on every page), first-visit hints with
"Show hints again", and a short confirmation after bulk Apply / Delete / Restore and note saves. Warehouse scorecard
groups CM SFG and all other warehouses, each with a subtotal. The sign-in page matches the dashboard and shows the logo
(assets/spyder-logo.jpg, served without signing in).

1v7: shared notes on Cloudflare Pages (functions/api/notes.js, KV key "overrides"): notes, override statuses,
Us / Them causes and deleted lines are shared with everyone who signs in, merged line by line (the newest edit
wins), each stamped with the editor's initials (asked once) and time; the sidebar shows "Notes shared · last edit".
Hosts without it, or an unreachable server, keep notes in the browser as before. New Cause select (Auto / Us / Them)
in the note editor, Build Risk rows and the linked-lines bulk bar (Set cause). Each upload records its At Risk lines
in an at-risk history (KV key "history", GET /api/history, last 52 export dates) for "first flagged" ages.

1v8: Order Health v2. Leading / Lagging tabs (arrow keys switch them; Export PDF prints both). Leading: open order
states (On track, Due this week, Rescheduled, Past due, No commit), top 6 at-risk reasons, When flagged (weeks since
first at risk, from the upload history), Us vs Them (cause = the one picked on the line, else the override, else the
SAP signal). Lagging: perfect order 12 mo and average days late 3 mo next to OTD, shipped, fill and reschedule hit,
each with the Us / Them split of its misses. Reason, cause and when-flagged filters from the charts (chips to clear,
kept in snapshots); Top offenders as $20k blocks; Search finds reasons and causes; get_overview / search_lines report
cause, leading and lagging. About these numbers on Order Health explains every number.

1v9: Ask AI rebuilt for four providers with the keys kept on the server (functions/api/ai/, Pages secrets
ANTHROPIC_API_KEY, OPENAI_API_KEY, GROQ_API_KEY, OPENROUTER_API_KEY): Claude and ChatGPT (paid), Groq and
OpenRouter free models (free). Provider and model picker grouped Paid / Free, a data-use notice and consent tick
per provider, tool loop in both the Anthropic and OpenAI formats, plain-English "not set up" help (also shown in

Gemini key is deleted from the browser).
